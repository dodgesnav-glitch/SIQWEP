# SIQWEP — портфолио

Статический сайт-портфолио на HTML, CSS и JavaScript. Не требует сборки и backend.

## Публикация на GitHub Pages

1. Создай новый публичный репозиторий на GitHub, например `siqwep-portfolio`.
2. Загрузи в корень репозитория файлы `index.html`, `style.css` и `script.js`.
3. Открой **Settings → Pages**.
4. В разделе **Build and deployment** выбери **Deploy from a branch**.
5. Выбери ветку `main` и папку `/ (root)`, нажми **Save**.
6. Через некоторое время GitHub покажет адрес опубликованного сайта.

## Что можно изменить

- Тексты и названия проектов — в `index.html`.
- Ссылки на проекты — в атрибутах `href` карточек.
- Цвета и оформление — в начале `style.css`, в блоке `:root`.
- Контакты — в секции `#contacts`.

## Важно

Ссылки на проекты и контактные данные добавлены на основании информации, предоставленной владельцем портфолио. Перед публикацией проверь, что все ссылки открываются и номер телефона указан верно.


## Изображения проектов

Фотографии первых четырёх проектов находятся в папке `assets/`. Не перемещай их отдельно от `index.html`, иначе изображения не загрузятся.
